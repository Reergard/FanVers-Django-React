# Алгоритмы отображения книг на главной странице

## Обзор

Реализованы два отдельных алгоритма для отображения книг на разных секциях главной страницы:
- **HomePage2.js** - новые книги (по дате создания)
- **HomePage3.js** - книги с недавними обновлениями глав

## Логика работы

### 1. HomePage2.js - Новые книги

**Критерии отбора:**
- Все книги из базы данных
- Сортировка по дате создания (новые сверху)
- Ограничение: 10 записей

**API Endpoint:** `/api/main/books-news/`

### 2. HomePage3.js - Книги с обновлениями

**Критерии отбора:**
- Книга создана больше суток назад (`created_at < now - 1 day`)
- Имеет главы с недавними обновлениями (`chapters__created_at >= now - 1 day`)
- Сортировка по времени последнего обновления главы (новые сверху)
- Ограничение: 10 записей

**API Endpoint:** `/api/main/books-recent-updates/`

### 3. Backend реализация

#### API Endpoint: `/api/main/books-news/` (HomePage2.js)

**Файл:** `backend/apps/main/api/views.py`

#### API Endpoint: `/api/main/books-recent-updates/` (HomePage3.js)

**Файл:** `backend/apps/main/api/views.py`

```python
@api_view(['GET'])
def books_recent_updates(request):
    # Время сутки назад
    one_day_ago = timezone.now() - timedelta(days=1)
    
    # Получаем книги с недавними обновлениями глав
    books_with_recent_chapters = Book.objects.filter(
        # Книга создана больше суток назад
        created_at__lt=one_day_ago,
        # Имеет главы с недавними обновлениями
        chapters__created_at__gte=one_day_ago
    ).annotate(
        # Время последнего обновления главы
        last_chapter_update=Max('chapters__created_at')
    ).order_by(
        # Сортировка по времени последнего обновления главы (новые сверху)
        '-last_chapter_update'
    ).distinct()[:10]
```

**Оптимизация запросов:**
- Использование `annotate()` для вычисления времени последнего обновления
- `distinct()` для исключения дубликатов
- Ограничение результата до 10 записей

**Функция форматирования времени:**
```javascript
const formatLastUpdate = (dateString) => {
  if (!dateString) return 'Недавно';
  
  const date = new Date(dateString);
  const now = new Date();
  const diffInHours = Math.floor((now - date) / (1000 * 60 * 60));
  
  if (diffInHours < 1) return 'Только что';
  if (diffInHours < 24) return `${diffInHours}ч назад`;
  
  const diffInDays = Math.floor(diffInHours / 24);
  if (diffInDays < 7) return `${diffInDays}д назад`;
  
  return date.toLocaleDateString('uk-UA');
};
```

- Название последней главы
- Время последнего обновления

- Оптимизированные SQL запросы
- Минимальное количество обращений к БД

### 4. Пользовательский опыт
- Понятное отображение времени обновления
- Актуальная информация о главах
- Логичная сортировка по активности
