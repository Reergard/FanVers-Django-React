# Система уведомлений FanVers

## Описание

Профессиональная система уведомлений с интеллектуальной фильтрацией ошибок. Автоматически фильтрует технические ошибки JavaScript и показывает пользователям только понятные сообщения.

## Основные возможности

✅ **Автоматическая фильтрация** - технические ошибки не попадают в UI  
✅ **Пользовательские сообщения** - показываются только понятные тексты  
✅ **Безопасность** - стек-трейсы и технические детали скрыты от пользователей  
✅ **Универсальность** - работает со всеми типами ошибок  
✅ **Простота использования** - не требует изменений в существующем коде  

## Использование

### Базовое использование

```javascript
import { useToast } from '../../components/CustomToast';

const MyComponent = () => {
  const { success, error, warning, info } = useToast();

  const handleAction = async () => {
    try {
      await someApiCall();
      success('Операція успішна!');
    } catch (err) {
      // Автоматически фильтруется и показывается пользовательское сообщение
      error(err);
    }
  };
};
```

### Показ пользовательских сообщений

```javascript
// Показываем конкретное сообщение
error('Невірний пароль');

// Или передаем объект ошибки - система сама извлечет понятное сообщение
error(apiError);
```

### Использование утилит для ошибок

```javascript
import { showUserError, logDeveloperError } from '../../utils/errorHandler';

try {
  await apiCall();
} catch (err) {
  // Логируем для разработчиков
  logDeveloperError('API Call', err);
  
  // Показываем пользователю
  showUserError(toast.error, err, 'Помилка при виконанні операції');
}
```

## Типы уведомлений

- `success` - успешные операции (зеленая рамка)
- `error` - ошибки (красная рамка)  
- `warning` - предупреждения (оранжевая рамка)
- `info` - информационные сообщения (синяя рамка)

## Автоматическая фильтрация

Система автоматически фильтрует:

- Стек-трейсы (`at functionName`)
- Webpack модули (`_WEBPACK_IMPORTED_MODULE_`)
- Технические ошибки JavaScript (`TypeError:`, `ReferenceError:`)
- Номера строк файлов (`.js:123:45`)
- React DevTools сообщения

## Настройка

### Длительность показа

```javascript
success('Повідомлення', { duration: 10000 }); // 10 секунд
error('Помилка', { duration: 8000 });         // 8 секунд
```

### Кастомные сообщения для ошибок

```javascript
// В errorUtils.js или authErrorUtils.js
export const CUSTOM_ERROR_MESSAGES = {
  specific_error: 'Понятное сообщение для пользователя'
};
```

## Интеграция с API

### Обработка HTTP ошибок

```javascript
// 401 - автоматически показывается "Необхідна авторизація"
// 403 - автоматически показывается "Доступ заборонено"  
// 404 - автоматически показывается "Нічого не знайдено"
// 500+ - автоматически показывается "Помилка сервера"
```

### Приоритет сообщений

1. **Серверные сообщения** (`error.response.data.detail`)
2. **HTTP коды статусов** (автоматические сообщения)
3. **Сообщения ошибок** (фильтрованные от технических деталей)
4. **Запасные сообщения** (fallback)

## Безопасность

- ✅ Технические детали скрыты от пользователей
- ✅ Стек-трейсы не попадают в UI
- ✅ Имена модулей и файлов скрыты
- ✅ Длина сообщений ограничена (200 символов)

## Примеры

### До (плохо)
```javascript
catch (err) {
```

### После (хорошо)
```javascript
catch (err) {

```

## Файлы системы

- `ToastContext.js` - основной контекст с фильтрацией
- `NotificationModal.js` - компонент модального окна
- `errorHandler.js` - утилиты для обработки ошибок
- `authErrorUtils.js` - специфичные для аутентификации ошибки
- `errorUtils.js` - специфичные для каталога ошибки

## Поддержка

Система автоматически обрабатывает все типы ошибок и не требует дополнительной настройки. Просто используйте `toast.error(err)` вместо `console.error(err)`.
